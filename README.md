# Professional Data Analyst — Superstore Sales Analysis

## Project Overview

This project analyzes the Superstore dataset using Python to understand
sales performance, profitability, regional performance, customer behavior,
and business trends.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Objectives

- Data cleaning and preprocessing
- Feature engineering
- Exploratory Data Analysis
- Correlation analysis
- Outlier analysis
- KPI automation
- Monthly and yearly trend analysis
- Business insights
- Automated reporting

## Key Results

- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Profit Margin: 12.47%
- Best-selling Category: Technology
- Best-performing Region: West
- Most Profitable Category: Technology
